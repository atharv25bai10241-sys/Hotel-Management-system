# Hotel Reservation System

## Problem Statement

Manual hotel reservation management can make it difficult to maintain
room availability, customer records, booking status, cancellation
refunds, and billing information consistently. The Hotel Reservation
System provides a Java-based solution to manage these operations through
a single menu-driven application.

## Scope of the Project

The project covers the management of hotel rooms, customers, and
reservations. It supports room availability tracking, customer
registration, booking creation and cancellation, check-in/check-out,
discount application, bill generation, refund calculation, booking
history, statistics, and local data persistence using serialized `.dat`
files.

The system is designed as a command-line application for managing hotel
operations without requiring an external database.

## Target Users

-   Hotel staff
-   Hotel reception/front-desk operators
-   Hotel administrators managing rooms, customers, and bookings

## High-Level Features

-   Room management and availability tracking
-   Customer registration and customer record management
-   Booking creation and booking search
-   Check-in and check-out management
-   Booking cancellation and automatic refund calculation
-   Percentage-based discounts
-   Bill generation with 18% GST calculation
-   Customer booking history and spending tracking
-   Upcoming bookings and hotel statistics
-   Input validation and custom exception handling
-   Data persistence using Java serialization
